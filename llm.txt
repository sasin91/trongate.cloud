## Framework
This project uses the Trongate PHP Framework v2.

## File Structure (Key Directories)
- `/config`: Configuration files (database, routing, app settings).
- `/db`: SQL migration files (numbered for load order).
- `/engine`: Core framework source code.
- `/modules`: Modular application logic (Controllers, Models, Views).
- `/public`: Entry point and static assets (CSS, JS).

## Core Configuration (config/config.php)
```php
<?php
define('BASE_URL', 'http://localhost/trongate_v2/');
define('ENV', 'dev');
define('DEFAULT_MODULE', 'welcome');
define('DEFAULT_METHOD', 'index');
```
